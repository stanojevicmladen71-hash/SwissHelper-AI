# SwissHelper AI – V15 Universal

Für GitHub/Render vorbereitet. Enthält die besprochenen UI- und Workflow-Korrekturen.

- zentrale UI-Sprache
- 20 Sprachen
- professionelle Übersetzung als eigener Bereich
- Formular-Helfer: erklären / Ausfüllen / fehlende Unterlagen
- Erkennung ausfüllbarer PDF-Felder
- Feld-für-Feld-Hilfe bei nicht ausfüllbaren Formularen/Scans
- Schweiz-Helfer mit Herkunft, Staatsangehörigkeit, Kanton und Zweck
- offizielle Schweizer Einstiegsquellen
- lokalisierter Free/Plus/Pro-Bereich
- X-Schließen für Panels
- Render-Konfiguration

Für echte KI-Analyse und professionelle Übersetzung wird auf Render `OPENAI_API_KEY` benötigt. Keine API-Schlüssel in GitHub hochladen.
